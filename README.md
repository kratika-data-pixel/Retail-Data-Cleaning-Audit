# Retail Data Cleaning & Quality Audit | Microsoft Excel

## Project Overview

This project demonstrates a structured approach to retail data cleaning, data validation, and quality auditing using Microsoft Excel.

The primary objective is to transform raw, inconsistent retail data into a clean, reliable, and analysis-ready dataset that supports accurate business reporting and decision-making.

## Business Objectives

- Identify and resolve data quality issues.
- Detect missing values and duplicate records.
- Standardize inconsistent data formats.
- Improve data accuracy and reliability.
- Prepare a structured data quality audit report.
- Make the dataset ready for further business analysis.
